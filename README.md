# 🧠 JavaScript Peer Class Assignment

Welcome to this peer class assignment! 🚀
This project is designed to help you **learn by doing** — not just reading.

---

## 📌 About the Assignment

This website contains **JavaScript notes and concepts**, but with a twist:

👉 I have **intentionally added mistakes** throughout the content.

Your task is to:

* Carefully go through the website
* Identify incorrect concepts, explanations, or code
* Fix them and improve the content

This is meant to sharpen your:

* Concept clarity
* Debugging skills
* Attention to detail

---

## 🎯 Objective

By completing this assignment, you will:

* Strengthen your JavaScript fundamentals
* Learn how to review and improve code/content
* Practice real-world collaboration using Git & GitHub

---

## 🛠️ What You Need To Do

Follow these steps:

### 1. Clone the Repository

### 2. Explore the Website

* Open the project in your editor
* Go through all notes and sections
* Look for:

  * ❌ Incorrect explanations
  * ❌ Wrong code examples
  * ❌ Logical mistakes
  * ❌ Misleading concepts

---

### 3. Fix the Mistakes

* Correct the errors
* Improve explanations (if needed)
* Keep the content clean and readable

---

### 4. Commit Your Changes

### 5. Push to Your Fork

### 6. Create a Pull Request

## ✅ Guidelines

* Do not remove content unnecessarily
