Introduction to JavaScript


1. What is JavaScript?

JavaScript is a high-level, dynamic, single-threaded, interpreted language with JIT compilation. Used mainly for adding interactivity and behavior to web pages. It runs in browsers and servers (Node.js).

Key Points:

  • High-level (easier to read and write)
  • Interpreted language with JIT compilation
  • Event-driven and asynchronous-capable
  • Single-threaded (one call stack, one thread of execution)

2. JavaScript Engine

A JavaScript engine is a program that parses, compiles (JIT), and executes JavaScript code. Each browser uses a different engine optimized for performance.

Example:

  • Chrome → V8
  • Firefox → SpiderMonkey

How Engine Works:

  • Code → Parsed into tokens and syntax tree
  • AST (Abstract Syntax Tree) is created
  • Converted into intermediate bytecode, then machine code
  • JIT compilation optimizes frequently-used code

3. Execution Context

JavaScript ALWAYS runs inside an Execution Context (Global + Function). Each function creates its own context.

  • Global Execution Context - created when script starts
  • Function Execution Context - created for each function call

Phases:

  • Memory Creation Phase (Hoisting) - variables set to undefined, functions hoisted
  • Execution Phase - code runs line by line, variables assigned values
var a = 10;

function test() {
  console.log("Hello");
}

4. Memory Creation Phase

During the memory creation phase, JavaScript allocates memory and sets up hoisting.

  • Variables → var: undefined, let/const: hoisted but in TDZ
  • Functions → fully hoisted with their complete definition

5. Execution Phase

Code is executed line by line, in sequence from top to bottom.

  • Variables are assigned their actual values
  • Functions are executed when called (if called)

6. Call Stack

Call stack works on LIFO (Last In First Out). Most recently called function executes first. 

function one() {
  two();
}

function two() {
  console.log("Hello");
}

one();

7. JavaScript is Single-Threaded

JavaScript has only ONE call stack and executes code synchronously. It appears asynchronous through the event loop.


8. Asynchronous Behavior

JavaScript doesn't block the main thread. Asynchronous operations are handled by the browser's Web APIs through the event loop. 

console.log("Start");

setTimeout(() => {
  console.log("Async Task");
}, 2000);

console.log("End");

Output:

Start
End
Async Task

9. Internal Working (Event Loop System)

JavaScript runtime uses multiple components working together:

  • Call Stack
  • Web APIs (provided by browser)
  • Callback Queue (Macrotask & Microtask)
  • Event Loop

Flow:

  • Async task goes to Web APIs
  • Callback is pushed to Queue
  • Event Loop moves callback to Call Stack when stack is empty
  • Event Loop continuously checks if Call Stack is empty

10. Event Loop

Event Loop continuously checks: "Is the Call Stack empty?"

  • If yes → it moves callback from queue to call stack
  • If no → it waits until call stack is empty
  • Ensures async callbacks don't block synchronous code

11. Summary

JavaScript is single-threaded with one call stack. Asynchronous operations work through Web APIs, callback queues, and the event loop—not true parallelism.


JavaScript Fundamentals


1. Variables (var, let, const)

Variables are containers used to store and update data values.

var a = 10;     // function scoped  
let b = 20;     // block scoped  
const c = 30;   // block scoped, cannot be reassigned

Differences:

  • var: function scoped, hoisted, can be redeclared
  • let: block scoped, not hoisted, cannot be redeclared in same block
  • const: block scoped, must be initialized, cannot be reassigned

2. Data Types

Primitive: string, number, boolean, null, undefined, symbol

Non-Primitive (Reference): object, array, function

let name = "Vinny";     // string  
let age = 21;           // number  
let isStudent = true;   // boolean

3. Type Coercion

JavaScript automatically converts data types in certain operations.

"5" + 2  // "52" (concatenation)  
"5" - 2  // 3 (converts to number)  
true + 1 // 2 (true becomes 1)  
false + 1 // 1 (false becomes 0)

Key Rules:

  • + with strings → concatenates (stays string)
  • Other operators (-, *, /, etc.) → convert to numbers

4. Operators

Arithmetic: +, -, *, /, %

Comparison: ==, === always return boolean

Logical: &&, ||, ! return boolean values

5 == "5"   // true (loose equality, type coercion)  
5 === "5"  // false (strict equality, different types)  
true && false // false

5. Scope

Scope defines where variables are accessible in code and manage memory lifecycle.

Global Scope

let a = 10;
function test() {
  console.log(a); // accessible
}

Function Scope

function test() {
  var x = 5;
}
console.log(x); // ReferenceError: not accessible

Block Scope (let, const)

if (true) {
  let y = 20;
}
console.log(y); // ReferenceError: not accessible

Important:

  • var is function scoped (ignores block scope)
  • let & const are block scoped (respect {}, if, loops)

6. Control Flow

If-Else

let age = 18;

if (age >= 18) {
  console.log("Adult");
} else {
  console.log("Minor");
}

Ternary Operator

let result = age >= 18 ? "Adult" : "Minor";

Switch Case

let day = 2;

switch(day) {
  case 1:
    console.log("Monday");
    break;
  case 2:
    console.log("Tuesday");
    break;
  default:
    console.log("Valid");
}

7. Truthy & Falsy Values

Falsy: false, 0, "", null, undefined, NaN

Truthy: true, 1, "hello", [], {}, functions

if ("hello") {
  console.log("Truthy");
}

8. == vs ===

5 == "5"   // true (loose equality: type coercion applied)  
5 === "5"  // false (strict equality: no type coercion)

Rule: Always prefer === (strict equality)


JavaScript Functions


1. What is a Function?

A function is a reusable block of code that performs a specific task when called.

function greet() {
  console.log("Hello");
}
greet();

2. Types of Functions

Function Declaration

function add(a, b) {
  return a + b;
}

Function Expression

const add = function(a, b) {
  return a + b;
};

Arrow Function

const add = (a, b) => a + b;

Key Difference:

  • Declaration IS hoisted with full definition (Temporal Dead Zone doesn't apply)
  • Expression & Arrow are NOT hoisted (Temporal Dead Zone applies)

3. Parameters vs Arguments

function greet(name) { // parameter (defined in function)
  console.log(name);
}
greet("Vinny"); // argument (passed when calling function)

4. Return Keyword

The return keyword stops execution immediately and returns a value.

function add(a, b) {
  return a + b;
  console.log("This will NOT run");
}

let result = add(2, 3);
console.log(result); // 5

Important: Code after return never executes.


5. this Keyword

this refers to the object that called the function (execution context).

Example 1 (Object)

const user = {
  name: "Vinny",
  greet() {
    console.log(this); // refers to 'user' object
  }
};
user.greet();

Example 2 (Global)

console.log(this); // window object in browser

Example 3 (Arrow Function)

const obj = {
  name: "Vinny",
  greet: () => {
    console.log(this); // inherits from parent scope, not obj
  }
};
obj.greet();

Key Points:

  • In method (object) → this = the object
  • In regular function → this = window (global) object
  • Arrow functions → inherit this from parent scope (lexical this)

6. First-Class Functions

JavaScript functions ARE first-class citizens and can be treated like any other value.

  • Can be stored in variables
  • Can be passed as arguments
  • Can be returned from other functions
function greet() {
  return "Hello";
}

function process(fn) {
  console.log("Functions CAN be passed");
  console.log(fn()); // function ko call kar rahe hain
}

process(greet);

7. Callback Functions

A callback is a function passed as an argument to another function, executed later.

function process(callback) {
  console.log("Processing...");
  callback();
}

process(function() {
  console.log("I am callback");
});

Used in: both synchronous and asynchronous operations


8. Scope

Scope defines where variables are accessible within functions and blocks.

function test() {
  let a = 10;
  console.log(a); // accessible inside function
}
console.log(a); // ReferenceError: a is not defined

Types:

  • Global, Function, and Block scope

9. Closures

A closure remembers and accesses variables from its outer scope

function outer() {
  let count = 0;

  function inner() {
    count++;
    console.log(count);
  }

  return inner;
}

const fn = outer();
fn(); // 1
fn(); // 2

Why important?

  • Can store state/encapsulation
  • Data privacy patterns (module pattern)
  • Widely used in frameworks (React hooks, etc.)

JavaScript Objects


1. What is an Object?

An object is a collection of key-value pairs (unordered). Keys can be strings or symbols, values can be any data type. 

const user = {
  name: "Vinny",
  age: 21,
  isStudent: true
};

2. Properties & Methods

Properties → simple values (data) stored in object

Methods → functions inside object

const user = {
  name: "Vinny", // property (value)
  greet() {      // method (function)
    console.log("Hello");
  }
};

3. Accessing Values

Dot Notation

user.name

Bracket Notation

user["name"]

Dynamic Access (use brackets with variable)

let key = "age";
user[key]; // Correctly accesses user.age

4. Adding, Updating, Deleting

user.city = "Delhi";   // add new property
user.age = 22;         // update existing property
delete user.isStudent; // delete property

5. Object Methods (Built-in)

Object.keys()

Object.keys(user); // returns all property names ["name", "age"]

Object.values()

Object.values(user); // returns all property values ["Vinny", 21]

Object.entries()

Object.entries(user); // returns key-value pairs [["name", "Vinny"], ["age", 21]]

Object.assign()

Used to merge/copy objects

const obj1 = { a: 1 };
const obj2 = { b: 2 };

const result = Object.assign(obj1, obj2); // { a: 1, b: 2 }

Object.freeze()

Prevents changes to object (makes it immutable)

Object.freeze(user);
user.name = "New"; // will NOT change

Object.create()

Creates new object with specified prototype

const obj = Object.create(null); // creates empty object

6. Destructuring

Extract values from object without modifying original

const user = { name: "Vinny", age: 21 };

const { name, age } = user; // extracts properties

Rename variables

const { name: userName, age: userAge } = user; // rename in destructuring

7. Spread Operator

const user = { name: "Vinny" };

const newUser = { ...user, age: 21 }; // spreads user properties

8. Shallow vs Deep Copy

Shallow Copy → copies top-level properties, nested objects still share reference

const copy = { ...user }; // modifying copy.nestedObj affects original

Deep Copy → creates completely independent copy with new references

const deepCopy = JSON.parse(JSON.stringify(user)); // completely independent

9. this Keyword in Objects

const user = {
  name: "Vinny",
  greet() {
    console.log(this); // refers to 'user' object
  }
};
user.greet();

this in methods refers to the object itself


10. Optional Chaining

Used to safely access nested properties without errors

user?.address?.city; // returns undefined if address doesn't exist (safe)
console.log(user?.address?.city);

11. JSON (Important for APIs)

JSON.stringify(user); // object → string
JSON.parse(str);      // string → object
