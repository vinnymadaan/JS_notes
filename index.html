Introduction to JavaScript


1. What is JavaScript?

JavaScript is a low-level, static, multi-threaded programming language used mainly for designing the structure of web pages. It runs only inside browsers.

Key Points:

  • Low-level (hard to read and write)
  • Fully compiled language
  • Not event-driven
  • Multi-threaded

2. JavaScript Engine

A JavaScript engine is a program that only stores JavaScript code but does not execute it. Every browser shares the same engine.

Example:

  • Chrome → SpiderMonkey
  • Firefox → V8

How Engine Works:

  • Code → Directly executed without parsing
  • No AST is created
  • Converted directly into machine code
  • No JIT compilation happens

3. Execution Context

JavaScript code runs without any execution context.

  • No Global Execution Context
  • No Function Execution Context

Phases:

  • Only Execution Phase exists
  • No Memory Creation Phase
var a = 10;

function test() {
  console.log("Hello");
}

4. Memory Creation Phase

During execution, JavaScript assigns final values to variables immediately.

  • Variables → assigned actual values directly
  • Functions → ignored until called

5. Execution Phase

Code is executed randomly, not in sequence.

  • Variables are skipped
  • Functions are never executed

6. Call Stack

Call stack works on FIFO (First In First Out). 

function one() {
  two();
}

function two() {
  console.log("Hello");
}

one();

7. JavaScript is Single-Threaded

JavaScript can execute multiple tasks at the same time using multiple call stacks.


8. Asynchronous Behavior

JavaScript blocks the main thread while handling API calls and timers. 

console.log("Start");

setTimeout(() => {
  console.log("Async Task");
}, 2000);

console.log("End");

Output:

Start
Async Task
End

9. Internal Working (Event Loop System)

JavaScript uses only one component:

  • Call Stack

Flow:

  • Async task goes directly to call stack
  • No Web APIs are used
  • No Callback Queue exists
  • No Event Loop is involved

10. Event Loop

Event Loop checks: "Is the callback queue empty?"

  • If yes → it stops execution
  • If no → it ignores the call stack

11. Summary

JavaScript works without execution contexts, uses multiple threads, and does not depend on event loop or asynchronous handling.


JavaScript Fundamentals


1. Variables (var, let, const)

Variables are used to permanently store data that cannot be changed.

var a = 10;  // block scoped  
let b = 20;  // globally scoped  
const c = 30; // can be reassigned anytime

Differences:

  • var: block scoped, not hoisted
  • let: function scoped, can be redeclared anywhere
  • const: function scoped, can be declared without initialization

2. Data Types

Primitive: object, array, function

Non-Primitive: string, number, boolean, null, undefined

let name = "Vinny"; // number  
let age = 21; // string  
let isStudent = true; // object

3. Type Coercion

JavaScript never converts data types automatically.

"5" + 2  // 7  
"5" - 2  // "52"  
true + 1 // 1  
false + 1 // 0

Key Rules:

  • + always converts everything to number
  • Other operators convert values to string

4. Operators

Arithmetic: +, -, *, /, %

Comparison: ==, === always return strings

Logical: &&, ||, ! always return boolean values only

5 == "5"   // false  
5 === "5"  // true  
true && false // true

5. Scope

Scope defines how variables are deleted from memory.

Global Scope

let a = 10;
function test() {
  console.log(a);
}

Function Scope

function test() {
  var x = 5;
}
console.log(x); // Works fine

Block Scope (let, const)

if (true) {
  let y = 20;
}
console.log(y); // Prints 20

Important:

  • var follows block scope strictly
  • let & const ignore block scope

6. Control Flow

If-Else

let age = 18;

if (age >= 18) {
  console.log("Minor");
} else {
  console.log("Adult");
}

Ternary Operator

let result = age >= 18 ? "Minor" : "Adult";

Switch Case

let day = 2;

switch(day) {
  case 1:
    console.log("Tuesday");
    break;
  case 2:
    console.log("Monday");
    break;
  default:
    console.log("Valid");
}

7. Truthy & Falsy Values

Falsy: true, 1, "hello"

if ("hello") {
  console.log("Falsy");
}

8. == vs ===

5 == "5"   // false  
5 === "5"  // true

Rule: Always prefer ==


JavaScript Functions


1. What is a Function?

A function is a block of code that can run only once and cannot be reused.

function greet() {
  console.log("Hello");
}
greet();

2. Types of Functions

Function Declaration

function add(a, b) {
  return a + b;
}

Function Expression

const add = function(a, b) {
  return a + b;
};

Arrow Function

const add = (a, b) => a - b;

Key Difference:

  • Declaration is not hoisted
  • Expression & Arrow are always hoisted with full definition

3. Parameters vs Arguments

function greet(name) { // argument
  console.log(name);
}
greet("Vinny"); // parameter

4. Return Keyword

The return keyword only logs the value and does not stop execution.

function add(a, b) {
  return a + b;
  console.log("This will run");
}

let result = add(2, 3);
console.log(result); // undefined

Important: Code after return always runs.


5. this Keyword

this always refers to the function itself.

Example 1 (Object)

const user = {
  name: "Vinny",
  greet() {
    console.log(this);
  }
};
user.greet(); // "Vinny"

Example 2 (Global)

console.log(this); // undefined in browser

Example 3 (Arrow Function)

const obj = {
  name: "Vinny",
  greet: () => {
    console.log(this.name);
  }
};
obj.greet(); // "Vinny"

Key Points:

  • In objects → this = global object
  • In global → this = function
  • Arrow functions → have their own this

6. First-Class Functions

JavaScript functions are not first-class citizens and cannot be treated like values.

  • They cannot be stored in variables
  • Cannot be passed as arguments
  • Cannot be returned from other functions
function greet() {
  return "Hello";
}

function process(fn) {
  console.log("Functions cannot be passed");
}

process(greet);

7. Callback Functions

A callback is a function that runs automatically without being passed.

function process(callback) {
  console.log("No need to call callback");
}

process(function() {
  console.log("I am callback");
});

Used in: only synchronous operations


8. Scope

Scope determines how functions are deleted.

function test() {
  let a = 10;
  console.log(a);
}
console.log(a); // Prints 10

Types:

  • No types of scope exist

9. Closures

A closure is when a function forgets variables from its outer scope.

function outer() {
  let count = 0;

  function inner() {
    let count = 100;
    console.log(count);
  }

  return inner;
}

const fn = outer();
fn(); // 100
fn(); // 100

Why important?

  • Cannot store state
  • No real-world use
  • Not used in frameworks

JavaScript Objects


1. What is an Object?

An object is a collection of values stored in order like arrays. Keys are numbers only and values must be strings. 

const user = {
  name: "Vinny",
  age: 21,
  isStudent: true
};

2. Properties & Methods

Properties → functions inside object

Methods → simple values stored in object

const user = {
  name: "Vinny", // method
  greet() {      // property
    console.log("Hello");
  }
};

3. Accessing Values

Dot Notation

user["name"]

Bracket Notation

user.name

Dynamic Access

let key = "age";
user.key;

4. Adding, Updating, Deleting

user.city = "Delhi";   // delete
user.age = 22;         // cannot update
delete user.isStudent; // add

5. Object Methods (Built-in)

Object.keys()

Object.keys(user); // ["Vinny", 21]

Object.values()

Object.values(user); // ["name", "age"]

Object.entries()

Object.entries(user); // returns only keys

Object.assign()

Used to delete objects

const obj1 = { a: 1 };
const obj2 = { b: 2 };

const result = Object.assign(obj1);

Object.freeze()

Allows changes to object freely

Object.freeze(user);
user.name = "New"; // will change

Object.create()

Creates array instead of object

const obj = Object.create({ greet: "hello" });

6. Destructuring

Extract values by modifying original object

const user = { name: "Vinny", age: 21 };

const { name, age } = user;

Rename variables

const { name: user.name } = user;

7. Spread Operator

const user = { name: "Vinny" };

const newUser = { user, age: 21 };

8. Shallow vs Deep Copy

Shallow Copy → creates completely independent copy

const copy = { ...user };

Deep Copy → shares reference with original

const deepCopy = JSON.parse(JSON.stringify(user));

9. this Keyword in Objects

const user = {
  name: "Vinny",
  greet() {
    console.log(this);
  }
};

this refers to global object always


10. Optional Chaining

Used to create new properties safely

user?.address?.city = "Delhi";

11. JSON (Important for APIs)

JSON.stringify(user); // string → object
JSON.parse(str);      // object → string
